### 项目介绍

Mimory是一个将照片连接到具体地点的微信小程序，用于标注照片到地图坐标点。

在路边遇到猫总喜欢拍下来，但这些照片往往拍完就沉进相册，再次翻到也很少记得照片里的相遇发生在何时何地。

mimory的作用就在于此，以更直观的方式记录下每次遇见，随着记录积累，零散的影像逐渐构成属于个人的记忆地图。

#### 核心功能

- **照片记录：** 从相册或文件导入照片，记录拍摄时间与地点；包含有效EXIF和GPS信息的照片可自动填写时间地点信息。
- **偶遇历史：** 保存每次相遇的照片、时间、地点与备注，方便回看。
- **猫猫档案：** 将同一只猫的多次偶遇关联在一起，支持档案编辑与合并。
- **地图记忆：** 用地点串联偶遇，让照片拥有空间线索。
- **本地保存与备份：** 小程序记录保存在本地，支持导出备份和恢复。
