# Mimory

**把与猫猫的偶遇，留在自己的记忆地图上。**

## 项目介绍

Mimory 是一个围绕猫猫偶遇设计的个人记录项目。

我们会拍下路边遇见的猫，却不一定记得照片里的相遇发生在什么时候、什么地方。Mimory 将照片与时间、地点和偶遇时的备注连接起来，让零散的影像成为可以回访的记忆。

每次偶遇都可以成为一条记录；多次遇见的同一只猫，也可以关联到同一个档案。随着记录积累，一次次相遇逐渐构成属于自己的猫猫记忆地图。

## 核心功能

- **照片记录：** 从相册或文件导入照片，记录拍摄时间与地点；包含有效 EXIF 和 GPS 信息的照片可解析相关信息。
- **偶遇历史：** 保存每次相遇的照片、时间、地点与备注，方便回看。
- **猫猫档案：** 将同一只猫的多次偶遇关联在一起，支持档案编辑与合并。
- **地图记忆：** 用地点串联偶遇，让照片拥有空间线索。
- **本地保存与备份：** 小程序记录保存在本地，支持导出备份和恢复。

## Web 展示

Web 页面用一张可展开、合拢和翻面的三折纸地图呈现 Mimory 的设计概念。猫猫标记、偶遇列表和纸张动画共同构成项目的交互展示，适配桌面与移动端。

Web 链接提供项目介绍与交互演示；照片导入、档案管理和数据备份属于 Mimory 小程序功能。
